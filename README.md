# EL DT

A mobile-first "sporting director" simulator built around Argentina's Liga Profesional. Pick a club, set a transfer budget, run five pre-season tasks (agenda, sell, loan, sign, formation), then simulate the full season and see where your club finishes.

Static HTML/CSS/vanilla JS, no build step, no framework, no dependencies.

## How to play

Open `public/index.html` directly in a browser, or serve the `public/` folder with any static server, for example:

```
npx serve public
```

Then:

1. Pick your club and set a transfer budget.
2. Complete the five hub tasks: pre-season agenda, sell, loan, sign, and formation.
3. Simulate the season and check the final table.

The transfer market includes the other 29 Liga Profesional clubs plus an international pool (Brasileirão, Liga Uruguaya, and select European/MLS/Liga MX clubs, including Argentines playing abroad). Foreign clubs are only a source of signable players — they never enter the league table or the season simulation.

## Refreshing the data

Squad, club, and pricing data live in `public/data/clubs.js`, generated by a scraper (Node 18+, no dependencies):

```
node scripts/scrape.mjs
```

It pulls Liga Profesional clubs, squads, coaches, colors, crests, flags, and season stats from promiedos.com.ar's embedded page data, plus a pool of foreign clubs for the international transfer market. Player market values are computed by this project's own formula — promiedos.com.ar does not publish market values, so the numbers here are estimates, not real transfer valuations.
